# Query API

`@xonava/core/query` exports `QueryPlan`, budgets, projections, read consistency, pagination, cursors/codecs, and search contracts. Validate plans with `validateQueryPlan`; it performs strict runtime shape and operator validation as well as complexity accounting, because TypeScript types are not a trust boundary. Unknown keys, custom prototypes, accessors, symbol keys, sparse arrays, cycles, malformed discriminants, and invalid scalar values are rejected. Use `DEFAULT_QUERY_BUDGET` only when its limits fit the route. `resolveProjection` intersects requested/route/queryable/readable fields. Cursor encoding/decoding requires an integrity port; always validate binding and stable sort before provider execution. Offset pagination takes `includeTotal: true` to ask for the total (`ListResult.rowCount`); without it no COUNT runs and `rowCount` is absent, and cursor pages report `hasNextPage`/`hasPreviousPage` instead of a total. Provider adapters compile the neutral plan—callers never inject SQL.
