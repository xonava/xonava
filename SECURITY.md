# Security policy

## Reporting a vulnerability

Report vulnerabilities privately. Do not open a public issue.

Use GitHub private vulnerability reporting: go to the repository's **Security** tab, choose **Report a vulnerability**, or open <https://github.com/Suriyaprakash-Somu/engine/security/advisories/new> directly.

Include:

- The affected package (`core`, `adapters`, or `testing`) and version.
- A description of the issue and its impact.
- Steps to reproduce, or a minimal test case.

Do not include real credentials, database URLs, or personal data in a report.

## Supported versions

This project is pre-release (`2.0.0-rc.2`). Only the latest pre-release receives security fixes. Earlier pre-releases are not patched.

## Bug bounty

There is no bug bounty program.
