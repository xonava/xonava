# core

Language-neutral framework semantics and their TypeScript reference contracts. Core has zero runtime dependencies, native ESM exports, and independently consumable capability subpaths. The package root is intentionally small.

See [`../../docs/spec`](../../docs/spec/README.md), the [TypeScript profile](../../docs/typescript/README.md), and [public exports](../../docs/reference/package-exports.md). Do not deep-import `src` or `dist`.
