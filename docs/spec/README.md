# Framework specification

Documents in this directory are normative unless a section says otherwise. They define observable semantics without prescribing a language, provider, transport, or internal algorithm.

Normative terms are defined in [normative language](normative-language.md); canonical terms in [terminology](terminology.md). TypeScript representations live in [`../typescript`](../typescript/README.md), not here.

Major areas: [kernel](kernel.md), [scope/security](security.md), [errors](errors.md), [persistence](persistence.md), [transactions/OCC](transactions-and-occ.md), [query](query.md), [events](events.md), [operations](operations.md), [execution](execution.md), [workflow](workflow.md), [serialization/durable formats](serialization-and-formats.md), and [certification](certification.md). Standalone capabilities each have their own page.
