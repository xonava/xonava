# Cache API

Import `CacheService`, `CacheAdapter`, `CacheCapabilities`, key helpers, and generation contracts from `@xonava/core/cache`. Construct a service with an adapter and optional `defaultTtlMs`, telemetry, `maxInFlight`, and `correctnessCritical`; this TypeScript implementation defaults omitted TTL to 120,000 milliseconds and bounds unresolved distinct resolvers. Correctness-critical mode rejects adapters unless they declare shared linearizable generations and implement both generation operations. Best-effort fallback uses one process-local epoch rather than retaining caller-controlled tags, so invalidation may conservatively miss more entries without resurrecting stale generations. Keys, tags, tag counts, TTLs, and in-flight resolver count are bounded. `get` returns `undefined` for absence; adapter failures become `CacheAdapterError` where the configured consistency requires failure. Use tag/generation APIs for invalidation and never treat instance-local miss coalescing as distributed locking. See the [normative cache spec](../spec/cache.md) and compile-tested example in `packages/testing/tests/documentationExamples.test.ts`.
