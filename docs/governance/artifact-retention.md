# Certification Artifact Retention

Certification evidence under `artifacts/framework-conformance` is intentional governance output.

Keep:

- named release-candidate evidence;
- the latest certified release evidence;
- milestone/phase evidence referenced by `phase-approvals.md`;
- aggregate manifests and source digests required to reproduce a certification claim.

Do not commit or retain as governance:

- failed ad-hoc development runs;
- temporary debug output;
- duplicate unnamed local runs;
- transient database files or worker scratch directories.

Ad-hoc runs should use a temporary external output location where supported. Evidence may be removed
only after confirming no governance document, aggregate certificate, or release record references its
run identifier. Package `dist` output and build-info are never certification evidence and are always
regenerated by the clean root build.
