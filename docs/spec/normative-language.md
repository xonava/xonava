# Normative language

The key words **MUST**, **MUST NOT**, **REQUIRED**, **SHALL**, **SHALL NOT**, **SHOULD**, **SHOULD NOT**, **RECOMMENDED**, **MAY**, and **OPTIONAL** express requirement strength as in RFC 2119/8174 when capitalized.

MUST/MUST NOT requirements are necessary for conformance. SHOULD/SHOULD NOT permit deviation only when the consequences are understood and documented. MAY marks permitted optional behavior. Examples and implementation notes are non-normative.
